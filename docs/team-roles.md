\## 3. Role Responsibilities



\### Scrum Master

\- Facilitates sprint planning, daily stand-ups, sprint review, and retrospective

\- Maintains the Jira board and ensures issue status reflects reality

\- Captures burndown chart snapshots at least twice per week

\- Removes blockers and escalates risks (API quota, network, scope creep)



\### Product Owner

\- Owns and prioritises the product backlog

\- Writes and refines user stories with acceptance criteria

\- Accepts or rejects completed stories against the Definition of Done

\- Represents the end-user perspective in scope decisions



\### Developers

\- Implement assigned user stories on feature branches

\- Raise pull requests and review at least one other member's PR per sprint

\- Write unit and prompt tests for the code they contribute

\- Reference the Jira issue ID in every commit message
