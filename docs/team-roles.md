## 3. Role Responsibilities

### Scrum Master
- Facilitates sprint planning, daily stand-ups, sprint review, and retrospective
- Maintains the Jira board and ensures issue status reflects reality
- Captures burndown chart snapshots at least twice per week
- Removes blockers and escalates risks (API quota, network, scope creep)

### Product Owner
- Owns and prioritises the product backlog
- Writes and refines user stories with acceptance criteria
- Accepts or rejects completed stories against the Definition of Done
- Represents the end-user perspective in scope decisions

### Developers
- Implement assigned user stories on feature branches
- Raise pull requests and review at least one other member's PR per sprint
- Write unit and prompt tests for the code they contribute
- Reference the Jira issue ID in every commit message

## 4. Sprint Schedule
Each development sprint is a strict two-week iteration as mandated by the CEP
brief. Sprint end dates are aligned to the deliverable deadlines published on
LMS; each sprint starts exactly two weeks before its deliverable is due.

| Sprint 2 | Mon 26 Oct 2026 | Sun 08 Nov 2026 | — |
| Sprint 3 | Mon 09 Nov 2026 | Sun 22 Nov 2026 | — |
| Sprint 4 | Mon 23 Nov 2026 | Sun 06 Dec 2026 | — |
| Report | 07 Dec 2026 | 13 Dec 2026 | P-3 Final Project Report |
| Demo | 14 Dec 2026 | 20 Dec 2026 | P-4 Final Demo & Viva |
Sprint 0 extends beyond the P-1 submission to cover team environment setup:
Python and Git installation for all members, SSH access configuration, GitHub
collaborator onboarding, and Jira account provisioning. Sprint 1 development
begins 12 October.
